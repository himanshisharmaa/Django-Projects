**# Django Projects Collection

This repository contains multiple Django-based projects demonstrating a wide range of backend development skills, including:

- Django Channels + WebSockets (real-time communication)  
- Django REST Framework (API development)  
- PDF generation using pdfkit + wkhtmltopdf  
- Classic Django CRUD apps  


---

##  Projects Overview

| Project Directory             | Description                                                         |
|-------------------------------|---------------------------------------------------------------------|
| `chatroom/mysite`             | Real-time chat app using Django Channels + WebSockets               |
| `WebBasedCV/webCV`            | Resume/CV generator with PDF download using pdfkit + wkhtmltopdf    |
| `EcommerceSite/ecommsite`     | E-commerce store project with Django features                       |
| `django_drf/mysite`           | Django REST Framework (DRF) project for building REST APIs          |
| `SocialMedia/socialM`         | Basic social media-like app with posts, users, and interactions     |
| `SiteScraper/mysite`          | Web scraping project using Django backend to process results        |
| `CalorieCount/mysite`         | Calorie tracking app using Django models + views                   |
| `expense/mysite`              | Expense tracker with Django models and templates                   |
| `newpro/mysite`               | General-purpose Django starter project                             |
| `vendor/mysite`               | Vendor management app (Django)                                     |

---

##  Requirements

Each project has its own `requirements.txt` file inside its folder.

General stack includes:
- Django ≥ 4.x
- channels (for WebSocket projects)
- djangorestframework (for DRF projects)
- pdfkit + wkhtmltopdf (for PDF projects)

To install, navigate into the project folder and run:
```bash
pip install -r requirements.txt
